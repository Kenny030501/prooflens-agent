# ProofLens v0.3：研究型结项报告

更新：2026-09-06（纽约）。负责人：达鸿儒 Hongru Da；产品研究与取舍由本人主导，代码和实验由 AI 辅助实现。交付对象是研究 Agent 的财务证据服务及求职作品集，不是已验证的商业产品。

## 核心结论

完成了从负面实验到代码修复的一轮产品迭代。此前 6 个配对任务中，普通流程与 ProofLens 最终标签均 24/24，证据合格任务均 5/6；接入完整核验链路的费用为 3.25 倍、中位耗时为 2.97 倍，未证明核心核验增益。

本轮修复后的真实模型回归为 **8/8**，同来源家族的新增主张为 **10/12**。回归确认、新增主张测试和真实市场效果分别报告，不用回归通过代替样本外优势。

## 当前系统

固定 AMZN、MRVL、NVDA，18 份 SEC／公司公告、690 个选定段落。调用方提交公司、截止日和 1–12 条主张，系统返回 supported / conflicted / insufficient、结构化事实、证据与恢复动作。网页用于演示和复核，REST 与 MCP 是主要接口。

程序负责来源准入、日期过滤、输入边界、原文逐字核对、确定性计算与预算。模型负责有界语义判断，不能添加新来源或交易动作。ISO 财务日历起止未知时返回空，不机械把 FY 当自然年。

原先 TF-IDF 容易被待核验的错误数字带偏。本轮加入弱化数字的第二查询与财务短语特征，两通道共用 24 段上限。计算采用命名事实操作数，由程序计算结果，检查单位、币种和数值在引用中的出现；完整指标／期间／会计口径的语义支持仍需复核。

复核标签与模型结论分开导出，不会制造新证据。数据库只存匿名事件和回执，不写入用户主张正文；最长十分钟的进程内缓存及上游提供商留存政策已在界面说明。真实调用回放明确标记 recorded_real_call，本次零费用，不是对新输入的实时验证。

| 实验 | 范围 | 结果 | 性质 |

| 历史诊断 | 120 条，含 32 条文档留出 | 115/120；留出 30/32 | 旧版本合成诊断，非当前总体准确率 |
| 角色问卷 | 1024 份、四模型／两供应商 | 高风险优先偏好、试用仍有不确定性 | 0 名真人，不是付费意愿证据 |
| 原同条件配对 | 6 对任务、24 条主张、18 次调用 | 双方 24/24 标签、5/6 合格；总费 $0.1492428 | 没有核心质量增益 |
| 本轮回归 | 8 条旧失败相关主张、2 次调用 | 8/8、请求全部完成 | 修复确认 |
| 本轮新增主张 | 12 条、3 次调用、3 条中文混合术语探针 | 10/12、请求全部完成 | 同来源家族的新题，非未见文档 |

本轮 5 次调用合计估算 **$0.0475716**。费用使用供应商返回 token 乘既有费率；实收账单未知。回执、预设标签与冻结哈希位于 `eval/release-v0.3/` 和 `eval/release-cases.json`，失败保留在分母中。

### 新题的两项失败

1. NVIDIA C2：模型尝试把输入中的 GAAP 数值当推导依据，引用只支持 Non-GAAP。操作数证据检查触发降级，未错误放行；这条正确主张仍没有完成核验。
2. NVIDIA C4：只有未来季度收入指引，预设为不足，模型返回冲突。属于“来源属性错误／缺实际证据”的标签边界；不在看到结果后修改预设标签。

上述是研究型发布的已知限制。未开展显著性检验、总体正确率推断或 bootstrap 扩样。不能把“没有观察到错误放行”写成错误率为零。

## 一轮可追溯迭代

| 失败证据 | 产品修改 | 验证 |
|---|---|---|
| A2 季度净利润证据未被检索 | 弱化数字查询＋财务短语特征 | 确定性测试确认季度原文可检索；真实模型 A2 4/4 |
| 三次减法输入与结果矛盾 | 命名事实操作数，由程序计算 | 19 项新增测试；相关真实回归 8/8 |
| 审阅意见容易与模型事实混淆 | 分离复核标签与模型判断，支持导出 | 浏览器验收与匿名事件 |

这体现“证据→取舍→实现→复测”，不证明模型服务普遍优于普通检索。

## 运行与复现

从仓库根目录运行 `npm ci`、`npm run db:local`，在服务端配置密钥后运行 `node scripts/dev-with-key.mjs /ABSOLUTE/PATH/authorized.env`。不含密钥也能浏览案例及真实调用回放；实时核验需要配置模型。

质量检查：`npm run typecheck`、`npm run lint`、`npm test`、`npx tsx tests/iteration.test.ts`、`npm run test:integration`、`npm run build`。基础 16 项与新增 19 项测试不产生模型费用；联通测试用无历史来源的日期，不调用模型。

付费复现前先核对预算和冻结哈希。`scripts/run-release-eval.mjs --freeze-only` 不调用模型；默认跳过已有结果。修改核心后须新建实验版本，禁止覆盖失败或将已读测试题继续称为未见样本。

## 后续路线图

P1：缺失会计口径的补检索；冲突／不足的独立标注规则；观察陌生 Agent 自主选用工具；比较紧凑返回和按需调用的完整成本。

P2：逐公司 ISO 财务日历、跨单位与中文专项集、来源持续更新。P3：在有采用与预算证据后考虑商业化、多人协作及生产 SLA。

停止条件：若强普通检索在同资料同预算下持续不劣，工具也没有降低集成成本，应调整定位或停止扩张，不能持续增加合成样本寻找有利结果。
