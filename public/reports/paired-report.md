# ProofLens 配对实验：当前未观察到核心核验增益

本轮 6 个配对任务中，两组最终标签均为 **24/24**，满足原定标签、行动与必要证据条件的任务均为 **5/6**。接入 ProofLens 的完整工作流费用约为基线 **3.25 倍**，中位耗时约为 **2.97 倍**。这些结果尚不足以支持“应当默认在每个同类任务中额外调用一次 ProofLens”。

执行日期：2026-09-05（美国东部时间）。完成 12/12 个工作流、18/18 次有 usage 回执的模型调用，无自动重试、截断或 schema 失败。总 token 估算费用 **$0.1492428**，低于本轮 $0.34 上限；尚未取得实收账单。

## 1. 比较了什么

场景为跨期、年度 / 季度、GAAP / Non-GAAP、指引 / 实际及派生计算核验。24 条新合成主张包括 11 条已支持、7 条明确冲突、6 条资料不足，来自 6 份新的一手公告。资料与旧版项目语料不重合，仍可能存在于模型训练资料中。

两组均使用 GLM-5.2、相同 TF-IDF 候选段落、同一截止日、同一最终输出要求与预算 / 时间上限。基线有明确财务核验指令，并非刻意削弱的裸模型。

普通流程：共同证据 → 最终 Agent 判断与引用。

ProofLens 流程：共同证据 → 现有 ProofLens 核心核验 → 最终 Agent 同时读取原文和核验结果，再作判断与引用。

ProofLens 核心代码、模型封装和提示词未修改，研究只在内存中载入新语料。后一组包含核心核验和最终消费结果的两次模型调用；这里的成本倍数只针对这条完整链路，不代表所有直接消费 API 结构化返回的集成方式。

## 3. 三个具体发现

### 共同检索瓶颈：判断对了，证据没有闭环

A2c 原主张把 Amazon FY2024 的 59.2 十亿美元净利润写成 Q4 2024。两组都识别出期间错配，检索却没有拿到 Q4 20.0 十亿美元的原文。因此未满足事前冻结的季度纠错证据要求，A2 在两组均不合格。

只引用年度值，并不能严格证明某季度值不可能相同；当前应该补检索季度实际数值，或明确限定为“已确认年度归属、季度值待补证”。多加一次相同证据范围内的模型核验没有补回这一缺口。

### 核心返回有 3 次计算契约错误，最终 Agent 再检查才恢复

ProofLens 中间返回的标签为 21/24。A2b、M1a、M1b 原始事实与增减方向正确，但模型输出的减法输入按 `[旧值, 新值]` 排列，却给出了“新值减旧值”的结果，与约定 `a-b` 不一致。校验器正确触发 `arithmetic_mismatch`，将 3 条主张降为资料不足。

最终 Agent 使用共同原文重新判断，恢复这 3 条已支持结论。这里观察到的是错误算式被拦截和下游恢复，不能写成 ProofLens 使最终判断更准确。如果客户端直接把中间返回当终局，会遇到本轮 3/11 条已支持主张被降级的问题。

### 一处解释口径警告，值得保留但不夸大

N2d 中，普通流程正确停止引用 Q2 实际净利润，却额外写出 Q1 净利润 19,894 百万美元，没有在句内说明这是 **Non-GAAP** 数值。完整来源段落保留了 Non-GAAP 标头；接入 ProofLens 的最终解释没有增加这一易混淆数字。

主张判定、行动和必需引用条件均未因此改变，主结果保留为两组 5/6。若采用更严格的“每个新增解释数值都必须独立写全口径”标准，普通流程为 4/6、ProofLens 为 5/6。此项为审阅后的敏感性说明，差异只来自一句附加解释，未做独立盲审，不能包装成稳健的 16.7 个百分点产品提升。

## 4. 产品取舍

本轮支持继续改进的优先级如下，**本次尚未实施这些修改**：

1. 优先补齐纠错所需的字段与期间证据，支持按“缺哪个字段”再检索；验收时看原本不合格的任务能否得到可核对的正确替代值。
2. 对计算采用明确命名的操作数与确定性计算，避免模型同时填写含义容易混淆的输入顺序和运算结果；在独立新样本中检验误降级是否减少。
3. 控制完整链路开销，比较紧凑的结构化返回、缓存及按需调用。当前最终 Agent 读取原文加完整审计返回，增加了输入 token。

费用分解：6 次 ProofLens 核心核验合计 $0.0550004，随后 6 次最终 Agent 合计 $0.0591216；普通流程 6 次最终 Agent 合计 $0.0351208。不能只展示核心核验的费用而漏掉下游消费成本。

本轮推翻的是“只要增加一层核验，就能在这些任务上自然获得可测增益”的预期。它没有证明整个产品方向无效，也没有证明 Agent 会自主选择、持续使用或付费购买服务；本轮是强制分组的工作流实验，尚未测试工具选择行为。

## 5. 可对外使用的表述

> 在 6 个配对财务核验任务、24 条源约束合成主张上，以相同模型、检索资料和判断要求比较普通 RAG 与 ProofLens 完整工作流。两组最终标签一致率均为 100%、证据合格任务均为 5/6；ProofLens 额外调用使本轮费用约增至 3.25 倍、中位耗时约增至 2.97 倍。分析定位到共同的期间证据检索缺口、3 次减法契约错误，以及一处附加解释的财务口径缺失，形成下一轮迭代优先级。
