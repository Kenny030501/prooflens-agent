## 标注、抽取与样本边界

- 24 条主张由 AI 根据一手资料编制，标签与最低引用条件在第一次正式调用前冻结。没有开展真人访谈，也没有两名独立人工标注者复核。
- 只使用每份公告前 18 个符合固定财务关键词及长度条件的块，共 105 段。文档的标题、部分段落或表格可能未被纳入，故资料缺失是有界检索问题，不能推断全网未披露。
- 存储的 `line_start` / `line_end` 指归一化 `.txt` 文本行，非原始 HTML 行或 SEC 页码。完整 HTML 和哈希可供复核；表格被线性化，因此列头与数据对应必须复查。
- 同一公司两道任务共用同一对公告，独立程度有限：6 个任务、3 个公司 / 文档对簇、每臂仅运行一次。没有使用 bootstrap 扩充样本或显著性检验。
- 原有 `audit()`、TF-IDF 检索和服务端模型封装保持不变。研究运行器只在内存中装载新语料，不修改网站代码、线上数据或提示词。两个流程均为离线核心调用，不包含实时网页搜寻、MCP 网络、浏览器操作或生产部署开销。
- 成本为供应商返回 token 数乘以项目现有费率假设的估算值，不是实收账单。超时或返回无 usage 时保留费用预留，不按零费用处理；所有失败均留在分母中。
- 最低来源 ID / 数值锚点检查不能证明语义支持。分析阶段逐条检查引用是否支持期间、单位、口径、修正内容；该检查为 AI 辅助审阅，不能表述为独立人工黄金标注。

财务数据核验规范促使本轮保留原始来源、区分发布时间与报告期，并明确哪些字段只有一手披露，避免把同源镜像或资料缺失包装成独立验证。
